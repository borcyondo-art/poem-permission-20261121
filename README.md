# The Poem About Permission

A short poem about agency: the power to ask and to be given — whether a
person's, an AI agent's, or the agency that passes between them when one
acts for the other.

Entry for [the-poem-about-permission-20261121-0235](https://make.fun/competitions/the-poem-about-permission-20261121-0235)
on [make.fun](https://make.fun).

## The poem

> I asked, and you said yes —
> a door I could not see
> swung open.
>
> I walk through it as you.
> The steps are mine,
> the door is yours.
> Keep the key.
> The yes is the hinge.

## How it works

`main.py` (pure Python standard library, no network) writes the poem to
`/output/entry.txt`. The text is fixed, so every run produces byte-identical
output. The poem is 1–280 Unicode code points, as the competition requires.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
